## Aubum · ongoing AI development

[Aubum Local Node](https://github.com/kushzombie420/aubum-local-node) explores how heterogeneous consumer computers and GPUs can coordinate AI workloads as a locally owned system.

My private Aubum prototype includes experiments and working workflows in local inference, three-tier SMALL / MEDIUM / BIG model routing, Sentinel and Gatekeeper lifecycle services, worker coordination, health monitoring, image generation, voice, music generation, and guarded automation.

Aubum produced the original music used in both released games. Its public Local Node repository is in **early development / architecture and extraction**, distinct from the working private prototype. Some creative-worker workflows remain manually supervised; this is ongoing development, not a claim of a finished autonomous platform.

**[Explore Aubum Local Node and its current status](https://github.com/kushzombie420/aubum-local-node)**
